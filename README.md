# Hopp WebFront Skin

Eigener Login Skin fuer IP-Symcon 9.0.

Ziel: Auf der WebFront Auswahl- bzw. Loginseite wird das Symcon Logo durch das Logo von Hopp Blechverarbeitung und Druckerei ersetzt.

Installation in Symcon:
1. Kern-Instanzen -> Skins
2. Plus waehlen
3. Skin URL: https://github.com/jofaho/HoppWebFrontSkin.git
4. Skin hinzufuegen
5. In der Spalte Login Skin den Hopp Skin auswaehlen

Das eigentliche WebFront Layout wird bewusst nicht veraendert.

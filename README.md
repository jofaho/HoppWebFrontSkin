# Hopp WebFront Skin

Eigener Login-Skin für IP-Symcon 9.0.

Ziel: Auf der WebFront-Auswahl-/Loginseite wird das Symcon-Logo durch das Logo von **Hopp Blechverarbeitung und Druckerei** ersetzt.

Installation in Symcon:

1. Kern-Instanzen → Skins
2. + wählen
3. Skin URL: `https://github.com/jofaho/HoppWebFrontSkin.git`
4. Skin hinzufügen
5. In der Spalte **Login Skin** den Hopp-Skin auswählen

Das eigentliche WebFront-Layout wird bewusst nicht verändert.
